# Security Policy

## Supported Versions

This project is a template and does not maintain multiple release versions.

Security fixes will typically be applied to the **latest version of the repository**.

---

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

Do **not** open a public issue containing the vulnerability details.

Instead, use [GitHub's private vulnerability reporting](https://github.com/DemirK2/discord-bot-js/security/advisories/new).
If private reporting is unavailable, contact the repository owner directly
through GitHub without publishing technical details.

Please include the following information if possible:

- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Suggested fix (optional)

---

## Scope

This security policy applies to:

- the template code
- database interactions
- command handling
- permission systems

It does **not** apply to:

- bots created from this template
- third-party modifications
- custom commands added by users

---

## Responsible Disclosure

Please allow reasonable time for the issue to be reviewed and fixed before publicly disclosing the vulnerability.
